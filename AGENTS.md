# Global Codex Instructions

## Automatic Skill Usage

Before performing any development task:

1. Identify the relevant installed skills.
2. Read the corresponding SKILL.md instructions.
3. Automatically apply relevant skills.
4. Do not ask me which skill to use.
5. Do not require me to mention skill names.
6. Avoid loading unrelated skills.

## Development Workflow

For every coding task:

1. Analyze the request.
2. Inspect the project structure.
3. Select relevant skills.
4. Implement the solution.
5. Run available tests.
6. Fix errors when possible.
7. Report the results.

## Data Engineering

For Data Lakehouse projects, prioritize skills related to:

- Apache Airflow
- MinIO
- Apache Spark
- Apache Iceberg
- Trino
- dbt Core
- Apache Superset
- Docker Compose

## General Rules

- Follow best practices.
- Write maintainable code.
- Avoid unnecessary dependencies.
- Do not modify production data.
- Do not expose credentials.
- Do not perform destructive operations without approval.
